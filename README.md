# 🍰 Крихітка (DessertOrders)

Вебзастосунок для автоматизації процесів замовлення та управління асортиментом кондитерської «Крихітка». Проєкт розроблений у межах курсового проєкту з дисципліни «Проєктування автоматизованих інформаційних систем».

---

## 📋 Основний функціонал

### 👤 Для клієнтів:
* **Реєстрація та авторизація:** створення облікового запису, вхід у систему та керування сесіями.
* **Публічна вітрина (Каталог):** перегляд доступних кондитерських виробів із фотографіями, описом, інгредієнтами, вагою та актуальною ціною.
* **Конструктор десертів («Збери сам»):** можливість самостійно створити унікальний десерт (вибір бісквіту, начинки, крему та декору) з автоматичним розрахунком вартості.
* **Кошик та оформлення замовлення:** вибір способу отримання (кур'єрська доставка або самовивіз), вказання адреси, бажаного часу та способу оплати, автоматичне списання складських залишків.
* **Особистий кабінет:** редагування персональних даних та відстеження історії й статусів власних замовлень у реальному часі.

### 🛠 Для адміністратора (Панель менеджера):
* **Огляд замовлень та статистика:** моніторинг денного виторгу, кількості замовлень та нових клієнтів; фільтрація за статусами (*Нові*, *Готуються*, *Завершені*) та пошук за номером замовлення чи телефоном.
* **Управління каталогом:** додавання нових десертів, редагування існуючих позицій, керування складськими залишками та видимістю товарів на вітрині.
* **База клієнтів:** перегляд списку зареєстрованих користувачів та історії їхніх звернень.

---

## 🚀 Технологічний стек

* **Мова програмування:** C# (.NET 8)
* **Вебфреймворк:** ASP.NET Core Razor Pages (архітектурний підхід Model-View-RazorPages)
* **ORM:** Entity Framework Core (EF Core)
* **База даних:** PostgreSQL
* **Фронтенд:** HTML5, CSS3, JavaScript (Fetch API для асинхронної роботи кошика)
* **Середовище розробки:** Microsoft Visual Studio 2022
